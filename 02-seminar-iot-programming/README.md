# Семинар. Программирование для IoT

- `Семинар_Программирование_для_IoT_Кайназар.docx` - заполненный бланк (части 1-4).
- `wokwi/<задание>/main.py` и `diagram.json` - проекты для симулятора Wokwi.

## Как запустить в Wokwi

1. wokwi.com → New Project → ESP32 → MicroPython.
2. Скопируйте содержимое `main.py` в main.py проекта.
3. Откройте вкладку `diagram.json` и замените её содержимое файлом из папки задания (схема подключения соберётся сама).
4. Нажмите ▶, затем Save и вставьте ссылку на проект в таблицу «Отчёт по части 3».

| Задание | Подключение |
|---|---|
| 3.1 | светодиод + резистор 220 Ом → GPIO 2 |
| 3.2 | DHT22 → GPIO 4, светодиод → GPIO 2; кликните по DHT22 и поставьте > 30 °C |
| 3.3 | кнопка GPIO 15 ↔ GND, светодиод → GPIO 2 |
| 3.4 | DHT22 → GPIO 4; топик `college/kainazar/temp`, проверка через HiveMQ WebSocket Client |
